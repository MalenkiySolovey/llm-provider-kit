# LLM Provider Kit

[English](./README.md) | **Русский**

`Llm.ProviderKit` — независимая .NET-библиотека для проверки каталога провайдеров, точного сопоставления endpoint-адресов, безопасного read-only HTTP-инспектирования, объединения инвентаря моделей и хранения явных фактов о провайдере. Библиотека не зависит от Codex, WinUI или Control Center и не владеет ключами провайдера.

## Возможности

- Разбор и проверка версионированных каталогов с сохранением неизвестных полей расширения.
- Сопоставление только по точному IDN-хосту и точному base URL — без суффиксного и подстрочного совпадения.
- Планирование только GET/HEAD, HTTPS (кроме loopback-тестов), строгий список доверенных хостов и запрет статических заголовков с учетными данными.
- Безопасное получение списка моделей и декларативных фактов баланса/использования с ограничением размера ответа, времени и redirect.
- Передача ключа через `IProviderCredentialSource` на время одной операции; библиотека не сохраняет ключ и не включает его в ошибки.
- Объединение точных model ID без слияния `:free`-вариантов; сохранение ручных и отключенных моделей и отметка устаревших записей без удаления.
- Неизвестные лимиты контекста и возможности моделей остаются неизвестными; доказательства хранятся явно, а интерпретация пользовательских overrides остаётся у приложения.
- Версионированный JSON CLI через stdin/stdout для проверки каталога и объединения инвентаря.

Библиотека выполняет только read-only проверки. Она не отправляет inference/canary-запросы и не выводит лимиты или возможности из названия модели.

## Сборка пакета

Пакет создаётся локально и не публикуется в NuGet:

```powershell
dotnet pack .\src\Llm.ProviderKit\Llm.ProviderKit.csproj -c Release -o .\artifacts\packages
```

`ProviderInspectionService` получает `IProviderCredentialSource`. Файловое хранилище, подписи, vault, маршрутизация и жизненный цикл приложения остаются обязанностью host-приложения.

## JSON CLI

CLI `llm-provider --json` принимает версионированный JSON через stdin. Поддерживаются `catalog.validate` и `inventory.merge`; значения входа не копируются в ответ.

## Проверки

```powershell
eng\verify.ps1
```

Проверка включает restore, build, тесты, форматирование, аудит зависимостей, pack и запуск synthetic consumer, который подключает только созданный пакет.
